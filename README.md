# Team Innerjoined — CSS 475

Team project for CSS 475. Built with React + Vite.

## Prerequisites

- **Node.js 26 (LTS)**: [nodejs.org](https://nodejs.org); confirm with `node -v`
- **Git**

## Getting started

```bash
git clone <repo-url>
cd <repo-folder>
npm install
npm run dev
```

## Scripts

| Command           | What it does                              |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | Start the local dev server                |
| `npm run build`   | Build for production into `dist/`         |
| `npm run preview` | Serve the production build locally        |
| `npm run lint`    | Check code with ESLint                    |
